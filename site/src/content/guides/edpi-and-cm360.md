## 为什么「灵敏度 2.0」这句话没有信息量

游戏内灵敏度必须和鼠标 DPI 一起看才有意义。400 DPI 下的 2.0 和 800 DPI 下的 1.0，手感**完全一样** —— 转同样角度需要的鼠标移动距离是相同的。

所以跨设备、跨选手比较灵敏度，只有两个可比口径：**eDPI** 和 **cm/360**。

## eDPI

```
eDPI = 鼠标 DPI × 游戏内灵敏度
```

- 400 DPI × 2.0 = **800 eDPI**
- 800 DPI × 1.0 = **800 eDPI**（同上，手感一致）
- 1600 DPI × 0.9 = **1440 eDPI**

职业选手的 eDPI 大致集中在 **800–1600**，中位数约 **1100**。低于 800 属于偏低灵敏度（大幅手臂流），高于 1600 属于偏高（手腕流为主）。

需要说明的是这个区间只是统计事实，不是推荐值。灵敏度高度个人化，最终要靠实际手感确定。

## cm/360

转满 360° 需要移动的鼠标距离（厘米）。这个数值直接对应肌肉记忆，比 eDPI 更贴近体感。

推导过程（别直接背常数，容易记错）：

```
CS2 的 yaw = 0.022 度/count
转满 360° 需要的计数 = 360 / (yaw × 灵敏度 × DPI) = 360 / (0.022 × eDPI)
英寸 = 计数 / DPI ？—— 不需要，上式已经消掉了 DPI：
  inches/360 = 360 / (0.022 × eDPI) = 16363.64 / eDPI
  cm/360     = inches/360 × 2.54   = 41563.64 / eDPI
```

验证几个常见组合：

| DPI | 灵敏度 | eDPI | cm/360 |
|---|---|---|---|
| 400 | 2.0 | 800 | 52.0 cm |
| 400 | 3.09 | 1236 | 33.6 cm |
| 800 | 1.0 | 800 | 52.0 cm |
| 1600 | 1.5 | 2400 | 17.3 cm |

注意第 1 行和第 3 行：DPI 和灵敏度都不同，但 eDPI 相同，cm/360 也完全一样。这就是「只有 eDPI 可比」的直观证据。

反过来，如果你知道自己想要的 cm/360，可以倒推游戏内灵敏度：

```
灵敏度 = 41563.64 / (目标 cm/360 × DPI)
```

例如想在 800 DPI 下得到 40cm/360：`41563.64 / (40 × 800) = 1.299`，即游戏内设 1.3 左右。

## CS2 和 CS:GO 需要换算吗

**不需要。** 两者的 yaw 都是 0.022，灵敏度数值 1:1 通用。CS:GO 时代的 2.0 搬到 CS2 还是 2.0，手感一致。

网上偶尔能看到「CS2 灵敏度要乘某个系数」的说法，那是把 CS2 与其他游戏（比如 Valorant、Apex）之间的换算搞混了。跨**游戏**换算确实需要系数（因为各家 yaw 不同），但 CS:GO → CS2 不需要。

## 开镜灵敏度系数

`zoom_sensitivity_ratio`（开镜灵敏度系数）决定开镜后的灵敏度是腰射的多少倍：

- 默认 **1.0**
- 职业选手常用 **0.8–1.0**
- **0.8189** 是一个经典取值，对应 16:9 下的 monitor-distance match（让开镜前后准星在屏幕上的移动距离感一致）

如果你主要打狙击，这个值值得单独调；如果用步枪为主，保持 1.0 通常就够了。

## Windows 灵敏度和「原始输入」

Windows 鼠标灵敏度（1–11 档）在第 6 档时是 1:1 无加速的。低于或高于第 6 档会引入插值，可能影响精度。

CS2 默认使用原始输入（raw input），直接读取鼠标硬件数据、绕过 Windows 的指针设置，所以理论上 Windows 灵敏度不影响游戏内表现。但为了排除干扰，多数选手仍会把 Windows 保持在第 6 档。

另外务必关掉 Windows 的「提高指针精确度」—— 那是鼠标加速，会破坏肌肉记忆。

## 怎么找到适合自己的灵敏度

1. **先定 DPI**。400 / 800 / 1600 都可以，选一个就不再改，这样后续调整只动游戏内灵敏度这一个变量。
2. **用 eDPI 区间做起点**。新手从 800–1200 eDPI 开始比较稳妥。
3. **实际测试**。进死亡竞赛或 aim 地图，练甩枪和跟枪各 10–15 分钟。
4. **精调**。用 [PSA 二分逼近法](/guides/psa-method)逐步收敛到个人最佳值，比一次性猜一个数靠谱得多。
